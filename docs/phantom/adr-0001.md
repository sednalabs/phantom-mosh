# ADR 0001: independent identity, upstream ancestry, separate evaluation

Status: adopted for this initial contribution; protocol details remain experimental.

Phantom Mosh is a separately named upstream-derived repository. A new wire
protocol and key lifecycle justify a distinct identity without discarding Mosh's
terminal semantics, attribution or Git history. The initial implementation is
not an official upstream protocol version. `v3/draft-01` is a domain-separation
identifier internal to this project, not an upstream allocation.

MoshWatch stays MoshWatch. Its PR #60, inspected at
`7e8888520bcc64dc2d6faaea036ea3e248613935`, remains historical evidence of the
clear-header experiment. The new record layer is implemented here. It retains
independent directional key updates but replaces the clear 18-byte header.
No source from moshpit or zmosh is imported; their alternative designs informed
the exploration, not this implementation's proof of correctness.

The transport, host-local instrumentation and adversarial evaluator have distinct
interfaces. Separate repositories help ownership and packaging, but do NOT
create scientific independence on their own. Input separation, independent
challenge construction, frozen candidates and nuisance/label audits remain
necessary even when all code is in separate repositories.

Rejected alternatives: renaming MoshWatch into an umbrella project; presenting
this as an official Mosh upgrade; shipping the PR60 clear header as concealment;
adding a new authentication system or large cipher-negotiation surface before
establishing a narrow reviewed transport. No decision here authorizes a release.
